# 百科/图鉴中“我来就好”“交给我吧”描述无法显示的根因调查

日期：2026-08-21

## 结论（根因）

**`CardModel.Owner` 的 getter 内部先调用 `AssertMutable()`**（`AbstractModel.cs:122`），
对 canonical（不可变）模型实例抛 `CanonicalModelException`。

百科/图鉴（NCardLibrary）直接使用 `ModelDb.AllCards` 里的 **canonical 卡牌实例**
（`NCardLibraryGrid._Ready` → `_allCards.Add(allCard)` → `NGridCardHolder.ReassignToCard`，
全程无 `MutableClone`）。

显示调用链：
`NCard.UpdateVisuals`（NCard.cs:440）→ `CardModel.GetDescriptionForPile`（CardModel.cs:1374 读 `Description`）
→ **SpiritModeDescriptionPatch.Postfix** → `IGotThis/InstinctCleanse.SpiritModeDescription`
→ `base.Owner` getter → `AssertMutable()` **抛异常**（发生在 `Owner == null` 判断之前）。

Postfix 异常向上传播 → 描述标签从未被赋值 → 百科中描述空白/不显示。

### 为什么此前的修复无效

之前加的 `if (base.Owner == null)` 判断触发的是 Owner **getter 本身**，而 getter 在返回
null 之前就抛异常了——null 比较根本执行不到。

### 为什么战斗里正常

战斗中的卡牌是 mutable 实例（Owner getter 的 `AssertMutable()` 通过），描述切换正常。
其他 ISpiritModeCard（基酒/鸡尾酒）的 `SpiritModeDescription` 不读 `Owner`（如 Gin 只按私有
`_mode` 字段返回），所以百科正常。

### 验证过的细节

- 本地化键全部存在且拼写正确（cards.json:325-336）：
  `PLUMA_CARD_I_GOT_THIS.description/_ALIVE_DESC/_MISSING_DESC`、
  `PLUMA_CARD_INSTINCT_CLEANSE.description/_ALIVE_DESC/_MISSING_DESC`。
- `IsMutable` 是 `AbstractModel` 的 public 属性（AbstractModel.cs:33），卡牌子类可直接访问；
  游戏自身在 `GetDescriptionForPile` 里就用 `base.IsMutable && (Owner?.IsOstyAlive ?? false)`
  守卫 Owner 读取（CardModel.cs:1387），可照搬该模式。
- Postfix 在百科中确实被触发：NCard.UpdateVisuals 无条件调用 GetDescriptionForPile
  （先取文本再按 Visibility 切换）。
- 连带影响：百科搜索框按描述文本过滤（NCardLibrary.cs:717 直接对 canonical 卡调
  GetDescriptionForPile）同样会抛异常，修复后一并解决。

## 修复方案（用户已确认，2026-08-21 实施）

`Scripts/Cards/IGotThis.cs` 与 `Scripts/Cards/InstinctCleanse.cs` 的 `SpiritModeDescription` 中，
把空值判断改为：

```csharp
if (!IsMutable || base.Owner == null)
{
    return new LocString("cards", "PLUMA_CARD_IGOT_THIS.description");   // InstinctCleanse 对应换成 INSTINCT_CLEANSE
}
```

行为变化：
- 百科：canonical → 显示通用 description（修复目标）。
- 战斗中：mutable 且 Owner 非空 → 保持现状（在场/不在场分支）。
- mutable 但 Owner 为 null 的场合（如升级预览的 MutableClone）：与之前相同，返回通用描述。

构建验证：dotnet build 0 错误。

## 验证点

- 主菜单卡牌图鉴：两张牌正常显示通用描述，标题/立绘/费用正常。
- 图鉴搜索框：按两张牌描述中的文字搜索不报错。
- 战斗回归：龙舌兰在场/不在场（或死亡）时描述仍正确切换；瞄准预览分支不变。
- 升级预览（图鉴升级视图）：显示通用描述不报错。
