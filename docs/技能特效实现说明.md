# 羽毛笔「渐入佳境」层数特效 / 治疗十字 实现说明

> 历史：
> 1. 最早做过一版「收割（Skill_2）」的技能特效（`CrowHarvestVfx` + `pluma/images/effects/crow/`），
>    原版收割特效与 3D 战场/光照绑定，复刻效果不理想，已整体删除。
> 2. 之后做过一版「手绘贴图 + Tween」的自制渐入佳境/治疗特效（`pluma/images/effects/flow/`），
>    观感与原版差距大，已整体删除。
> 3. 现行版本改为**直接烘焙明日方舟官方特效 prefab**，素材与原版同源，见下。

## 1.5 原版渲染逻辑（烘焙必须复刻的三条）

以 `crow_attack_buff_02` 为例，翻 prefab JSON 得到：

1. **发射方向**：`ShapeModule.type = 4`（`ParticleSystemShapeType.Cone`）、`angle = 0`，Cone 轴向是**局部 +Z**；
   节点 `star` / `trail` 的 `rot` 是四元数 `[-0.707107, 0, 0, 0.707107]`（绕 X 轴 -90°），
   于是 **局部 +Z → 世界 +Y**，粒子一律往上飞。早期按"球面随机方向"发射，所以特效往四周炸开，是错的。
2. **渲染模式**：`particleSystemRenderer.m_RenderMode = 1`（`"renderMode": "stretch"`，Stretched Billboard）
   + `m_LengthScale = 2` + `m_RotateWithStretchDirection = true` → 四边形**沿速度方向拉长 2 倍并跟着旋转**，
   这才是"窄箭头 + 细长光条"的来源。
3. **各轴尺寸**：`InitialModule.size3D = true`，宽 = `startSize`、高 = `startSizeY`
   （`star` 0.02–0.04 × 0.2–0.4 极细长；`trail` 0.06–0.11 × 0.08–0.1），再乘 `SizeModule` 的 x/y 曲线。
   早期按单一边长画正方形，所以箭头又粗又方。

`fx_bake.py` 对应实现：`quat_rotate` / `quat_from_euler_deg` 处理节点与 Shape 旋转；`spawn_one()` 按 `shape_type` 取方向；
`draw()` 在 `stretch=True` 时按速度角度旋转并按 `m_LengthScale` 拉伸；粒子宽高分别存 `p.w / p.h`。

## 2. 素材来源与烘焙流程

官方 prefab 数据（Unity ParticleSystem 逐字段导出，含 23,364 个特效）：

```
D:\game\卫戍协议-觉醒之战-Windows玩家完整包-20261115\卫戍协议-觉醒-玩家版\public\assets\local\fx\prefabs\
```

其中与羽毛笔相关的 13 个 `crow_*.json`，用到的贴图从游戏本体导出：

```
E:\game\Arknights bilibili\games\Arknights Game\Arknights_Data\StreamingAssets\AB\Windows\refs\fx\texture\{star,flow,mask,shizi,trail,crow,...}.ab
```

烘焙脚本 `D:\plumamod2\pluma\.tmp_rt\fx_bake.py`（PIL + numpy）：

- 复刻 `InitialModule / EmissionModule(m_Bursts, rateOverTime) / ShapeModule / VelocityModule /
  SizeModule / ColorModule / RotationModule / ClampVelocityModule`，步长 1/120s；
- 用 `curve_eval` 做 Unity AnimationCurve 的三次 Hermite 插值，`gradient_eval` 做 color/alpha 关键帧插值；
- 帧率 30fps、单帧 256×256、起点固定在图帧中心，按"可见像素到原点的 99 分位距离"自动缩放；
- 输出前把颜色预乘 alpha、alpha 二值化（≥0.004 记 255），因为游戏里用 `BlendMode=Add`（Godot 会再乘一次 alpha）。

三条烘焙命令（产出在 `.tmp_rt/fx_bake/`）：

```bash
python .tmp_rt/fx_bake.py --tag flow_aura  --bright 3.0 --dur 3.0 crow_attack_buff_02
python .tmp_rt/fx_bake.py --tag heal_cross --white --bright 3.0 --dur 1.2 crow_attack_buff_01
```

`--white` = 忽略 prefab 的颜色曲线统一出白色（治疗原版是青绿色，需求要银白十字）；
`--size-mul` = 粒子尺寸倍率（原版靠 bloom 撑亮，搬过来放大一点更明显）；
`--only a,b` = 只烘焙指定节点（治疗曾用它去掉过密的星点）。

最终资源：`pluma/images/effects/official/{flow_aura,heal_cross}.png`

| 文件 | 帧数 | 布局 | 尺寸 | 时长 | 循环 |
| --- | --- | --- | --- | --- | --- |
| `flow_aura.png` | 90 | 8 列 | 2048x3072 | 3.0s | 是 |
| `heal_cross.png` | 36 | 8 列 | 2048x1280 | 1.2s | 否 |

## 3. 代码结构

`Scripts/Vfx/OfficialFx.cs` —— `public static class OfficialFx`，纯运行时构建，不用 `.tscn`、不用 `GpuParticles2D`：

- `Play(Creature? owner, Kind kind, float scale, Color? tint, bool anchorBottom)`：
  · `TestMode.IsOn` 直接返回；
  · 节点**挂到小人 `NCreature` 自身**（Control），坐标 `node.MakeCanvasPositionLocal(node.VfxSpawnPosition)`，
    `ZIndex = 40` + `ZAsRelative = true`，并按 `GetGlobalTransform().Scale.X` 反算缩放；
  · 用 `AnimatedSprite2D` + `SpriteFrames`（每帧是 `AtlasTexture` 的矩形切片），材质
    `CanvasItemMaterial { BlendMode = Add }`，`Centered = true`；
  · `anchorBottom = true` 时 `sprite.Position.Y = -cell * (scale - 1) / 2`，即放大后**底边停在原处**；
  · 播完 `frames / fps` 秒后用 `Tween` 自毁。
- 精灵表按文件名缓存（`FrameCache`），共享一份叠加材质。

`Scripts/Vfx/FlowVfx.cs` 只是薄封装（保留 `MaxStacks = 12` 与 `PlayStackGain / PlayHeal` 两个入口），
调用点在 `Scripts/Powers/FlowState.cs`（叠层）、`Scripts/Relics/ReaperBadge.cs`、`Scripts/Relics/AquaDawn.cs`、
`Scripts/Powers/ReaperHealingPower.cs`（治疗）。

## 4. 压制原版治疗特效

`Scripts/Vfx/PlumaHealVfx.cs`：

- `PlumaHealVfx.Begin() / End()`：用计数器开一个"本次治疗不要播原版十字光"的作用域（可在 `finally` 里收尾）；
- `[HarmonyPatch(typeof(VfxCmd), nameof(VfxCmd.PlayOnCreatureCenter))]` 的 Prefix：
  作用域内且 `path == "vfx/vfx_cross_heal"` 时跳过。其余 VFX（含奥斯提的 `vfx/vfx_heal_osty`）不受影响。

## 5. 改完后怎么生效

```bash
dotnet build                    # 只更新 dll（复制到 mods\pluma\）
```

改了 `pluma/images/effects/official/*.png` 还要重导 pck（**贴图在 pck 里，漏这一步等于没改**）：

```bash
"d:\Godot\...\Godot_v4.5.1-stable_mono_win64_console.exe" --headless --path D:\plumamod2\pluma --import
"d:\Godot\...\Godot_v4.5.1-stable_mono_win64_console.exe" --headless --path D:\plumamod2\pluma --export-pack "pluma" D:\plumamod2\pluma\pluma.pck
```

再把 `pluma.pck` + `pluma.dll` 复制到 `E:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\pluma\`。

> 注意：`arknights_assets/` 里有 11MB 的 2048 立绘，必须靠 `.gdignore` 挡掉，否则会被打进 pck（pck 会涨 10MB）。
