# 羽毛笔「渐入佳境」光环 / 治疗特效 实现说明

> 历史：
> 1. 最早做过「收割（Skill_2）」技能特效（`CrowHarvestVfx`），与原版 3D 战场绑定，复刻失败，已删。
> 2. 之后做过「手绘贴图 + Tween」的自制版本（`pluma/images/effects/flow/`），观感差距大，已删。
> 3. 再之后把官方 prefab **烘焙成精灵表**（`flow_aura.png` / `heal_cross.png`），粒子被压成一帧帧低清bitmap，
>    实际进游戏几乎看不见，已删。
> 4. 现行版本：**按官方 prefab 参数在 Godot 里逐粒子复刻**（CPU 粒子 + Sprite2D + 自写 canvas_item shader），
>    贴图直接从方舟本体导出，参数逐字段来自 prefab JSON，见下。

三条渲染规则必须照抄，否则形状就不对：

1. **发射方向**：Shape `Cone` 轴向是局部 `+Z`，节点 `rot` 四元数 `[-0.707107,0,0,0.707107]`（绕 X −90°）
   把 `+Z` 转到世界 `+Y` → 粒子一律向上。本 mod 是 2D 侧视，直接把「向上」映射成屏幕向上。
2. **stretch 渲染**：`len = sizeY × lengthScale + speed × velocityScale`，四边形沿速度方向拉长并旋转，
   **粒子在「头」端**（`position = pos - dir*len/2`）；这才是「细长光条/箭羽」的来源。
3. **各轴独立尺寸**：`size3D` 时宽 = `startSize`、高 = `startSizeY`；`size3D false`（baoshan/shizi）时两轴
   共用同一个随机基数，再各乘自己的 Size 曲线。

## 3. 代码结构

`Scripts/Vfx/OfficialFx.cs`（配置 + 资源加载）与 `Scripts/Vfx/OfficialFxInstance.cs`（运行时）：

- `OfficialFx.CreateAura(Creature?)`：建 `OfficialFxInstance`（`ZIndex 35`）+ `star`/`trail` 两个 `FxEmitter`，
  `Loop = true`、`Prewarm` 预铺满，挂在 `NCreature` 上；
- `OfficialFx.PlayHeal(Creature?)`：建 `baoshan1`/`shizi_1`（`ZIndex 40`），`PlayOnce(1.6f)` 后自毁；
  官方 buff 挂在**身体中心**（buff prefab 的根不在脚下），所以两个发射器的 `NodeYUp` 额外加 0.9 个单位：
  `baoshan1 = 0.9`、`shizi_1 = 0.52`；
- `OfficialFx.PlayDeploy(Creature?)`：入场特效（官方 `crow_start_01`），三套系统都挂在**身体中心**
  （`NodeYUp 0.9`）：`smoke`（10 团烟，`smoke_17` 6×6 序列帧，`startColor` 深灰两色 `0.441 → 0.066`，
  普通混合，所以是「暗烟」而不是白雾）+ `crow2`（10 根**纯黑**羽毛，`startColor` 黑，自转 + 限速）
  + `crow`（`flipbook_161` 4×4 序列帧火星，tint alpha 0.431），`ZIndex 45`、`PlayOnce(1.8f)`；
  由 `Scripts/Vfx/DeployVfxHook.cs`（`[RegisterSingleton] HookedSingletonModel(HookType.Combat)` 的
  `AfterRoomEntered`）在每个 CombatRoom 里轮询等玩家节点出现后触发；
- `OfficialFx.PlayMaxStack(Creature?)`：仍是 `max_stack.png` 精灵表（30 帧 @30fps）；
- 比例：**不再用固定常量**。`MeasurePxPerUnit()` 读 `NCreature.Visuals.Bounds.GetGlobalRect().Size.Y`
  （spine 包围盒，已含 `ori_character.tscn` 里 `Visuals` 的 0.7 缩放）当作小人屏幕高度，
  按「方舟小人 ≈ 1.8 个 Unity 单位」换算 `像素/单位 = 身高 / 1.8`；
  **锚点是小人原点（脚底）**——`%CenterPos` 在玩家视觉里默认停在 (0,0)，只有 Wuppy 逻辑才会改它，
  所以不要再自己减半个身高；
- 坐标：实例 `Position = node.MakeCanvasPositionLocal(node.VfxSpawnPosition)`，`Scale = 1 / 小人全局缩放`，
  粒子位置/尺寸都乘 `像素/单位`；每个发射器带 `NodeYUp`（官方节点相对锚点的高度，米）——
  `star 0.387`、`trail 0.161`、`baoshan 0.9`、`shizi 0.52`、入场三套 0~0.05；
- `trail` 的 `trail_116` 纹理箭头朝后，渲染时 `FlipH = true` 才和上升方向一致；
- 每个粒子一个复用的 `Sprite2D`（池化，`MaxParticles = 64`），逐帧算宽高/旋转/颜色；
- 支持官方 `ClampVelocityModule`：`LimitSpeed` + `Dampen`，超过上限时按「每步」逼近上限（参考实现不乘 dt），
  治疗十字与入场羽毛靠它「炸开后立刻刹住」；
- 支持官方 `UVModule` 序列帧（`FlipCols/FlipRows`，整段生命周期均匀播一遍，行序按 Unity 左下原点翻转）。
  图集是整张一张贴图，所以序列帧粒子**每个粒子一份 `ShaderMaterial`**，用 `u_frame_rect` 取自己的格子；
- 支持官方 `startColor` 的 MinMaxGradient（TwoColors）：`StartColor`/`StartColorB` 加逐粒子随机插值 `ColorT`
  （深灰烟、黑羽毛就是这么来的）；
- `Opacity` → `u_gain`：官方在 HDR + bloom 管线里渲染，StS2 是纯 sRGB、没有 bloom，细小的加色十字会几乎看不见。
  这个系数只放大最终 alpha（不改官方颜色本身），`shizi_1 = 2.6`、`baoshan1 = 1.5`，其余默认 1；
- 支持官方 `UVModule` 序列帧与 `RotationModule` / `startRotation`（`SpinMin/SpinMax` 弧度每秒、`RandomRotation`）；
- 两种材质 shader（运行时字符串构造，按 `additive`/`dissolve` 缓存）：
  · AlphaBlend：`c = tex * 2 * COLOR * tint`，普通混合（`star` 的黑色 tint 因此表现为「暗影」）；
  · Dissolve Add：同上再乘溶解遮罩 `m = clamp((d - amount + border*r)/border)`；官方着色器输出是
    `vec4(c.rgb, m*c.a)` + `SrcAlpha, One`，等价于叠加 `c.rgb * c.a`（`c` 里已含 ×2，**不要**再乘 2，
    否则会亮一倍、彩虹色过饱和），实现里输出 `vec4(c.rgb * c.a, 1.0)` + `render_mode blend_add`；
  · 主图/遮罩 UV 支持 tiling+offset+`TIME` 滚动（`shizi_1` 的 `_UVTween`）。
- `Scripts/Vfx/FlowVfx.cs` 仍是薄封装（`MaxStacks = 12`、`SyncAura` / `PlayStackGain` / `PlayHeal` / `PlayMaxStack`），
  调用点在 `Scripts/Powers/FlowState.cs`（叠层/移除）、`Scripts/Relics/ReaperBadge.cs`、
  `Scripts/Relics/AquaDawn.cs`、`Scripts/Powers/ReaperHealingPower.cs`（治疗）。

## 4. 压制原版治疗特效

`Scripts/Vfx/PlumaHealVfx.cs`：

- `PlumaHealVfx.Begin() / End()`：计数器开一个「本次治疗不要播原版十字光」的作用域（`finally` 收尾）；
- `[HarmonyPatch(typeof(VfxCmd), nameof(VfxCmd.PlayOnCreatureCenter))]` 的 Prefix：
  作用域内且 `path == "vfx/vfx_cross_heal"` 时跳过；其余 VFX 不受影响。

## 5. 改完后怎么生效

```bash
dotnet build                    # 只更新 dll（自动复制到 mods\pluma\）
```

只要动了 `pluma/images/effects/**`（贴图增删改）就必须重导 pck，**贴图在 pck 里**：

```bash
"d:\Godot\Godot_v4.5.1-stable_mono_win64\Godot_v4.5.1-stable_mono_win64_console.exe" --headless --path D:\plumamod2\pluma --export-pack pluma D:\plumamod2\pluma\pluma.pck
```

导出进程跑完 `[ DONE ] savepack` 后不会自己退出，需要 `taskkill`。再把 `pluma.pck` 复制到
`E:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\pluma\`。

> 注意：`arknights_assets/` 里有 11MB 的 2048 立绘，必须靠 `.gdignore` 挡掉，否则会被打进 pck。
