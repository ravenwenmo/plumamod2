# 羽毛笔「渐入佳境」层数特效 / 治疗十字 实现说明

> 历史：最早还做过一版「收割（Skill_2）」的技能特效（`Scripts/Vfx/CrowHarvestVfx.cs` + `pluma/images/effects/crow/`），
> 因为原版的收割特效与 3D 战场/光照绑定、复刻效果不理想，已按需求整体删除，本文只描述现行实现。

## 1. 特效一览

| 触发时机 | 表现 | 代码入口 |
| --- | --- | --- |
| 获得「渐入佳境」层数（每次 +N） | 身边浮起 N 支白色小箭头（最多同时 3 支），向上飘并淡出 | `FlowVfx.PlayStackGain(owner, gained, total)` |
| 层数**首次**达到 12 | 脚下光环扩散 + 中心爆光 + 6 颗星芒外飞 + 3 支加长箭矢冲天 | 同上（内部 `MaxBurst`） |
| 已满 12 层后继续叠层 | 脚下补一圈柔和的轻脉冲 | 同上（内部 `Pulse`） |
| 收割者特性（造成攻击伤害后回血） | 银白十字放大-回缩-淡出 + 背后柔光 + 2 颗小星 | `FlowVfx.PlayHeal(owner)` |

配色（`FlowVfx.cs` 顶部）：`Silver = (0.93, 0.97, 1.00)`、`StarCyan = (0.78, 0.90, 1.00)`，与方舟原版的冷白银白高光一致。

## 2. 素材来源

五张贴图全部由 `D:\plumamod2\pluma\.tmp_rt\gen_flow_tex.py` 用 PIL 程序生成（不含任何游戏本体资源）：

| 文件 | 尺寸 | 画法 |
| --- | --- | --- |

放在 `pluma/images/effects/flow/`。改风格改生成脚本重跑即可，注意重跑后要重新导出 pck。

## 3. 代码结构

`Scripts/Vfx/FlowVfx.cs` —— `public static class FlowVfx`，纯运行时构建，不用 `.tscn`、不用 `GpuParticles2D`：

- `Prepare(Creature)`：`TestMode.IsOn` 直接返回 null；否则取 `owner.GetVfxContainer()`
  （战斗中 = `NCombatRoom.CombatVfxContainer`，identity 变换，入树前设好 `Position` 即可）
  + `NCombatRoom.Instance.GetCreatureNode(owner).VfxSpawnPosition` 作锚点，建一个临时 `Node2D` 根节点。
- `MakeSprite(...)`：`Sprite2D` + 共享 `CanvasItemMaterial { BlendMode = Add }`（叠加混合，发光感）。
- 动画全部用 Godot 原生 `Tween`（不是自写时间轴）：
  · `Rising(sprite, duration, delay, rise, drift)`：淡入 → 上移 → 淡出，位置/缩放/透明度并行；
  · 十字用 `TransitionType.Back + EaseType.Out` 做"弹出"手感；
  · 满层爆光用 `TransitionType.Cubic + EaseType.Out` 做扩散。
- 横向位置用黄金比例错开（`(index * 0.618) % 1`），确定性、不用随机数，多支箭不会重叠。
- `AutoFree(root, seconds)`：`TweenInterval` + `TweenCallback`（`GodotObject.IsInstanceValid` 判活）后 `QueueFree`。
- 贴图按 `ResourceLoader.Exists` 检查并缓存，缺失时 `GD.PushWarning("[pluma] 缺少渐入佳境特效贴图：...")` 并静默跳过，不会崩。

## 4. 接入点

- `Scripts/Powers/FlowState.cs` → `AfterPowerAmountChanged` 里，`if (power != this || amount <= 0) return;` 之后：
  `FlowVfx.PlayStackGain(base.Owner, (int)amount, (int)base.Amount);`
  （`total >= MaxStacks && total - gained < MaxStacks` 判定"首次满 12 层"，只爆一次。）
- `Scripts/Powers/ReaperHealingPower.cs` → `AfterDamageGiven` 里 `await CreatureCmd.Heal(...)` 之后：
  `FlowVfx.PlayHeal(base.Owner);`

两者都是纯本地视觉，不影响多人同步与回放。

## 5. 改动后要做什么

1. `dotnet build`（更新 dll，并自动部署到 `mods\pluma\`）；
2. 贴图在 `pluma/images/effects/flow/` 下，**必须重新导出 `pluma.pck`**：
   `godot --headless --path . --import` → `godot --headless --path . --export-pack pluma pluma.pck`；
3. 把 `pluma.dll` 与 `pluma.pck` 一起放进 `mods\pluma\`。
4. 注意 `arknights_assets/` 里有 `.gdignore`，立绘等素材不会被打进 pck（否则 pck 会白白大 10MB）。
