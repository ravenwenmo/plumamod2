## 一、API 查证结果（全部从源码确认）

| 问题 | 结论 |
| --- | --- |
| 受击前异步钩子 | `AbstractModel.BeforeDamageReceived(PlayerChoiceContext, Creature target, decimal amount, ValueProp props, Creature? dealer, CardModel? cardSource)`，由 `Hook.BeforeDamageReceived` 遍历 `runState.IterateHookListeners(combatState)` 异步调用（Hook.cs:415-424）。**amount 是传值通知，不能改数值**。 |

| 钩子挂载点 | RitsuLib `HookedSingletonModel(HookType.Combat)`（SlashingComboSingleton 先例）：战斗级单例，可 override 上述两个钩子。 |

| 主动/被动区分 | `CardPlay.IsAutoPlay` 字段（OnPlayWrapper 构造 CardPlay 时设置，CardModel.cs:1922）。 |

## 二、已与用户确认的设计决策

1. **创伤触发机制（被动）**：居合被动打出只造成 6 伤害 + 施加翻倍标记（命中后），**不额外触发创伤**；敌方攻击结算后正常触发的那层创伤被标记放大 ×2/×3 并照常消耗 1 层（"不额外消耗创伤"）。主动打出：6 伤害 + 标记 + 立即触发放大创伤。
2. **被动触发条件**：仅伤害来源是敌方怪物（`dealer.IsMonster`）时减半并自动打出。
3. **卡图**：IaiSlash.png 不存在，用 `print_test_card_images.py` 生成占位图。

## 三、实现方案

### 1. 新建 `Scripts/Powers/WoundAmplifyPower.cs`（创伤翻倍标记）

- `Type = PowerType.Buff`（不被人工制品阻挡）、`StackType = PowerStackType.Counter`（可叠加，1=×2，2=×3）。
- `IsVisibleInternal => false` 隐藏图标。
- `AfterSideTurnEnd`：参与者包含持有者时 `PowerCmd.Remove(this)`（兜底清理，正常情况由创伤触发消耗）。
- 本地化：powers.json 加简单条目。

### 2. 修改 `Scripts/Powers/OpenWound.cs` 的 `TriggerMultiple`

```csharp
// 造成创伤伤害前检查翻倍标记：本次伤害 = Amount × (1+层数)；
// 伤害造成后清空标记，确保只有一次增伤。其余逻辑不变。
int amplify = base.Owner.GetPowerAmount<WoundAmplifyPower>();
decimal damage = base.Amount;
if (amplify > 0) damage *= 1m + amplify;
await CreatureCmd.Damage(choiceContext, base.Owner, damage,
    ValueProp.Unpowered | ValueProp.Unblockable, base.Owner);
if (amplify > 0) await PowerCmd.Remove<WoundAmplifyPower>(base.Owner);
await PowerCmd.Decrement(this);   // 层数照常 -1
```

### 3. 新建 `Scripts/Cards/IaiSlash.cs`（3 费稀有攻击牌）

- 3 费、Attack、Rare、AnyEnemy、切割关键词、DamageVar 6。
- `OnPlay`：6 伤害 → `UnblockedDamage > 0` 判定命中 → 施加 WoundAmplifyPower（未升级 1 层 / 升级 2 层）→ 若 `!cardPlay.IsAutoPlay` 再调 `target.GetPower<OpenWoundPower>()?.TriggerMultiple(choiceContext, 1)`（立即触发放大创伤）。
- `OnUpgrade`：`AddKeyword(CardKeyword.Retain)`。

### 4. 新建 `Scripts/IaiSlashTriggerSingleton.cs`（被动触发器）

`[RegisterSingleton]` + `HookedSingletonModel(HookType.Combat)`：

- `ModifyDamageMultiplicative`：目标为玩家、dealer 为敌方怪物、手牌有居合 → 返回 0.5m（伤害减半）。
- `BeforeDamageReceived`：同样条件 + 静态防重入标志 → `CardCmd.AutoPlay(choiceContext, hand.Cards.OfType<IaiSlash>().FirstOrDefault(), dealer)`（取索引最小=最左一张）。

### 5. 时序（敌方单段攻击，玩家手牌 1 张居合）

```
CreatureCmd.Damage(敌人攻击玩家)
 ├─ ModifyDamage → 减半（0.5×，手牌有居合）
 ├─ BeforeDamageReceived → 自动打出最左居合（牌先移出手牌 → 6伤害 → 命中 → 施加标记）
 ├─ 玩家受到减半伤害
 └─ Postfix(OpenWound patch) → TriggerMultiple → 标记 ×2/×3 → 清空标记 → 创伤层数 -1
```

多段攻击：每段重复上述流程，每段打出一张居合（至多一张），每段创伤各放大一次。
递归检查：居合 6 伤害与创伤伤害的 target 都是敌人 → `CanTrigger` 不成立 → 不会连锁。

### 6. 多人安全

- 减半：同步纯计算钩子，各端状态一致。
- 自动打出：`CardCmd.AutoPlay` 命令路径 + 传入明确目标（dealer），无随机。
- 无 `new Random()`；居合自身伤害 dealer 始终为玩家（FromCard）；创伤伤害 dealer 为持有者自身（沿用现有逻辑）。
- 静态防重入标志在串行 await 链中安全，各端本地一致。

### 7. 本地化与资产

- `cards.json`：`PLUMA_CARD_IAI_SLASH.title/description`（描述用 `{Damage:diff()}`）。
- `powers.json`：`PLUMA_POWER_WOUND_AMPLIFY_POWER.*` 简单文本。
- 生成 `pluma/images/cards/IaiSlash.png`、`pluma/images/powers/WoundAmplifyPower.png` 占位图。

## 四、需要用户测试的验证点

1. 主动打出：6 伤害 + 敌人立即掉"创伤层数×2"伤害、创伤层数 -1；升级后 ×3 且卡牌保留在手。
2. 被动：敌方攻击时玩家伤害减半、最左居合自动打出（对来源敌人）、随后创伤×2；多段攻击逐段触发多张。
3. 居合被完全格挡：不施加标记、创伤正常触发。
4. 无创伤层数时：标记不消耗，敌方回合结束时移除（不显示图标）。
5. 多人：双方都能看到同步的减半/自动打出/创伤放大。
